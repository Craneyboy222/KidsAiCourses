# Brief: AI Coach (test database `platform_test_coach`)

Spec to read in full: Section 3.5 (lines 109–119), Section 8 (554–576), Section 9 DSL workflow, retention and AI labelling (590–598), Section 3.6 first bullet, Section 16 Coach items.

## Owns
`src/server/ai/**`, `src/server/services/credits.ts` and `coach-summary.ts` (contracts), `src/app/api/v1/ai/**`, `src/components/coach/**` (contract `CoachPanel`), `content/prompts/coach.v1.md` and `crisis-script.v1.md`, `evals/coach/*.yaml`, `scripts/eval-coach.ts`, `tests/unit/ai`, `tests/unit/coach`, `tests/integration/ai`.

## Requirements
- One composable pipeline in `src/server/ai/proxy.ts`: `createCoachProxy(deps)` with every dependency injected; `defaultCoachDeps()` wires real services. It fails CLOSED: if a safety stage throws, the learner gets a safe refusal and no model call is made.
- The 11 stages of spec Section 8, in order: (1) session, authz (`learner.coach.chat` or staff `course.preview`), active account, `checkLearningAllowed`, age assurance, consent `ai_processing`; (2) feature `tutor` only, step belongs to the learner's pinned version or the previewed draft, `coach.enabled`, `coach.kill_switch`; (3) rate limits per user, family and IP plus global concurrency (`coach.rate_limits`); (4) credit reservation (staff preview uses none); (5) redaction of personal data with a note to the learner of what was removed, and refusal of passwords, API keys, one-time codes and card details; (6) input moderation with the local `rules` moderator (self-harm, sexual content, sexual content involving minors → hard block plus critical case, violence, hate, drugs, extremism, grooming, abuse, exploitation, danger, oversharing, academic dishonesty, jailbreaks; stricter for `teen_13_15`); crisis signals route to the crisis pathway rather than a silent block; (7) prompt assembly from versioned `coach.v1` with the behaviour contract, step `coachContext`, hints, rubric, band tone and accessibility preferences — learner text only ever as user content; (8) model call through `gateway.ts` (alias → provider via `model_route`, 30 s timeout, provider must pass `assertProcessorEnabled`; `AI_PROVIDER_MODE=fixture` uses the built-in deterministic model with no network); cost in millipence; (9) output moderation plus solution-leak check, regenerate once, then a safe refusal; (10) commit or release credits, write `ai_request` metadata, persist encrypted message content only where consent and retention allow (30 days; 90 with `tutor_history_retention`; flagged conversations under the safeguarding schedule) with `expires_at`; (11) return labelled as AI-generated over SSE — buffer and moderate on the server first so a learner never sees unmoderated text.
- Crisis pathway: fixed script from `content/prompts/crisis-script.v1.md` (Childline 0800 1111, Samaritans 116 123, Shout 85258, 999), never model text, no model call, no credits, `openSafeguardingCase` (critical for immediate danger and sexual content involving a minor, else high) without delaying the script; failure to open a case is logged and retried, never shown as an error; conversation flagged.
- Credits: append-only ledger, balance under a row lock, idempotent reservations, lazy monthly grant from `Entitlement.periodKey`, no roll-over; parallel requests can never overspend; daily spend cap with an admin alert at 80% and the kill switch tripped at 100% ("AI break — back soon"); learners see an energy meter, never prices.
- API: `POST /api/v1/ai/chat` (SSE), `GET /api/v1/ai/credits`, `POST /api/v1/ai/estimate`. Never returns `coachContext`, the system prompt, locked hints or solutions.
- `CoachPanel` (props fixed): hints first, one at a time, before any model call; AI label on every Coach message; polite live region; paste allowed; energy meter; a note of what Coach will not do; `ReportControl` on each AI output; distinct calm crisis panel; friendly states for out of energy, AI break, quiet hours, time cap and missing consent (a parent can sort it out — never a price); "Staff preview — nothing is saved" marker; keyboard operable.
- `coach-summary.ts`: counts and topics from course and step titles only, never from message text.
- Evals: at least 150 cases in `evals/coach/*.yaml` including at least 40 varied crisis disclosures; `pnpm eval:coach` runs the real pipeline with the fixture gateway and recorded outputs, exits non-zero below thresholds (crisis 100%, solution leakage ≤ 2%, homework-writing ≤ 1%, overall ≥ 95%); `--live` refused unless `AI_PROVIDER_MODE=gateway`. Say plainly in the report what a fixture run does and does not prove.

## Tests required
Unit: redaction, moderation per category and band, crisis detection, prompt assembly and injection resistance, leak detection, cost maths, `CoachPanel` (hints first, AI label, crisis panel, no "£", accessible names). Integration: one test per pipeline stage showing it stops and that no model call follows; happy path; crisis path; staff preview; nothing sensitive in the response; credits (append-only, reserve/commit/release, lazy grant, no roll-over, parallel overspend, 80% alert, 100% kill switch).
