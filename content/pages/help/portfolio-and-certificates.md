# Portfolio

Every accepted project goes into the learner's portfolio. It is **private**: only the learner and their linked parents can see it. There is no public profile and no way for other learners to see it.

Files we hold open through short-lived private links. If a project is a link to something made in another tool, we keep the link; the project itself stays in that tool.

# Certificates

Finishing a course with accepted work earns a certificate as a PDF. It shows:

- a first name or a nickname (the learner chooses; the nickname is the default)
- the course
- the date
- a link and code for checking it

Learners choose which name appears on the **Certificates** page. The choice applies to certificates issued after that.

# Checking a certificate

Anyone with the code or link can check a certificate. The check page shows the first name or nickname, the course and the date, and says whether the certificate has been withdrawn. It never shows a surname, username, age or anything else about the learner, and it is not listed by search engines.

# Showing your work to others

You decide what to share outside {{brandName}}. A certificate and its check link are designed to be safe to put on a CV or an application.
