You make your project in real tools run by other companies. Every course has a "Tools you'll need" section so you know what you are getting into before you start.

# What it shows for each tool

- the tool's name and a link to its official website
- what it costs, or whether there is a free plan
- the minimum age in that company's own terms
- one of: you can use it, a parent needs to approve it, or a parent runs the account for you
- a setup guide, with the date it was last checked

# Setup guides

Each tool has a step-by-step guide: creating the account, confirming it, choosing the free plan, the privacy settings we recommend, and then how to do the project in that tool.

# Things to know

- These tools are not ours. Each has its own rules and privacy policy.
- What you type or make in a tool goes to that company, not to us. We only get what you hand in.
- Tools change. If a screen does not match the guide, press Report on the step and choose "This doesn't match what I see".
- **Never share a password, sign-in code or key** for a tool with anyone, including us and Coach. We will never ask.

# Leaving the site

When you follow a link to a tool, we tell you that you are leaving {{brandName}}. Your place in the course is kept, so you can flip back to read the next step.
