An invite code lets a teenager set their own password, so a parent never needs to know it.

# For parents

- When you add a child, choose the invite code option instead of setting a password. You can also create a new code later from your dashboard, for example if a password has been forgotten.
- A code works **once** and for **72 hours**.
- Give the code to your child directly. Do not post it anywhere others can see it.

# For teenagers

1. Go to the **Join** page (there is a link on the sign-in page).
2. Type in the code your parent or carer gave you.
3. Choose a password of at least 10 characters. Three random words work well.

After that, sign in with your username and your new password.

# If the code does not work

- It may have run out (72 hours) or been used already. Ask your parent or carer for a new one.
- Check for letters and numbers that look alike.
- After several wrong tries there is a short wait before you can try again.
